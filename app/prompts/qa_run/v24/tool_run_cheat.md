Run a cheat the game registered, to set up a precondition (`invoke_cheat`). `name` is from the cheat list in your first message; `arguments` maps its parameter names to values. `target` is for a cheat on a component: part of a selector from the `Cheats now` line is enough, and leaving it out lets the game pick its only instance. Only cheats your test case allows and the game lists as now. The answer carries the game's message and the screen after it. Read the cheats skill first.
