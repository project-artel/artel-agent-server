Start a behavior the game registered: code that gives per-frame input inside the game and keeps running while you think. `name` is from the behavior list in your first message, `arguments` its parameters, `target` part of a selector from the `Behaviors now` line, `max_seconds` 1 to 300 (default 30). The answer gives its id; the pulse view shows it running, and its end reaches you in a later tool result. Keep observing while it runs. Read the behaviors skill first.
