# 2026-11-24 — 행동 준비 확인과 반복 입력 중단

- Date: 2026-11-24
- Jira: ARTEL-1464
- Status: Implemented

## Goal

후보가 하나일 때도 기존 준비 조건을 이용해 실행하거나 기다린다. 완료 조건이 거짓인 상태에서 같은 입력이 효과 없이 반복되면 실행을 멈춘다.

## Context

Survivors 실행 #449에서 메뉴는 준비됐지만 생성된 `done()`이 거짓이어서 hover가 213회 반복됐다. ArcaneCasters 실행 #451에서는 로그인 상태가 그대로인데 자격 증명 입력을 반복했다.

## Approach

- [x] 후보 수와 관계없이 준비 여부가 불확실할 때 기존 Jev 기다림 질문 사용
- [x] 단일 대상 결정 및 기다림 유예 시간 유지
- [x] 입력 전에 완료 조건을 다시 확인하고, 실제 행동·대상과 해당 목표의 관측값으로 반복 판단
- [x] 기존 복구 예산이 있으면 Planner에 요청하고, 소진됐으면 중단 이유 기록

## Validation

준비 상태, 기다림, 대상 변경, 이동 중인 값, 마지막 입력의 완료 및 복구 예산에 대한 회귀 테스트와 #449·#451 실행 기록을 이용한다.

## Risks & Rollback

준비 조건이 없는 단일 행동에는 기다림을 묻는 호출이 추가된다. 문제가 생기면 이전 Agent 이미지로 되돌릴 수 있다.
