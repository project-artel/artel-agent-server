# macro 중간 대사 기록 제거

사용자 요청으로 #265를 종료하고 macro 실행 중 지나간 대사를 따로 모아 반환하는 기능을 제거했다. channel의 ShownTextLog, PULSE 누적, MacroSession의 text_mark, macro 응답의 대사 목록과 전용 파일을 제거했다. 현재 scene의 최신 text 관찰과 macro 실행·일시 정지·재개·취소·결과 fold는 유지한다.

새 prompt v40~v42에서는 대사 목록 안내를 제거한다. 기존 v1~v39는 재현용으로 변경하지 않는다. 고정된 옛 판본으로 macro를 실행할 때도 runner는 중간 대사 이력이 제공되지 않는다는 현재 계약을 system context 뒤에 명시한다.

QA 검토 순서는 #263 → #266 → #275 → #291이다. #291의 선택적 시각 점검 skill을 유지하며, 시각 점검이 필요할 때 현재 화면을 확인한다. 실제 게임 반복 QA에서의 성능 차이는 이번 제거 작업에서 측정하지 않았다.
